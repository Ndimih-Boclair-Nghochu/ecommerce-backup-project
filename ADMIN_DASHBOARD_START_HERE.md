## ❓ FAQ

**Q: Can I add my own products?**  
A: Yes! Click "Add Product" in the Products tab.

**Q: How do I manage orders?**  
A: Go to Orders tab, select order, change status dropdown, or view receipt.

**Q: Can I create sub-admins?**  
A: Yes! Go to Sub-Admins tab and click "Add Sub-Admin".

**Q: Where are my changes saved?**  
A: Automatically to data.json file in the server folder.

**Q: How do I see customer chat?**  
A: Orders must exist first. Go to Chat tab to see conversations.

**Q: Can I change the shipping fees?**  
A: Yes! Go to Shipping tab and update amounts.

**Q: What if something breaks?**  
A: Restart with `npm run dev` and clear browser cache.

**Q: How do I deploy this?**  
A: See deployment section in ADMIN_DASHBOARD_AUDIT_COMPLETED.md
