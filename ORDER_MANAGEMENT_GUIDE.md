## 🚀 Usage Guide

### Finding Orders
1. **View all orders** - System loads all orders by default
2. **Filter by status** - Click stat cards at top (Pending, Processing, etc.)
3. **Search for specific order** - Type in search box (name, email, phone, ID)
4. **Sort results** - Choose sort option (newest, oldest, highest value, lowest value)

### Updating Order Status
1. **Click status dropdown** on order row
2. **Select new status** from options
3. **Change is saved automatically** ✅
4. **Notification confirms** the update

### Bulk Status Updates
1. **Select orders** using checkboxes (or Select All)
2. **Choose status** from "Bulk Update Status" dropdown
3. **Click "Apply to X orders"** button
4. **All selected orders** updated at once

### Viewing Order Details
1. **Click "View" button** on order row
2. **Details expand below** the order
3. **Shows complete order information:**
   - All buyer details
   - Delivery information
   - Full item list with prices
   - Complete financial breakdown
4. **Click "Hide" to collapse** details

### Deleting Orders
1. **Click "Delete" button** on order
2. **Confirm deletion** in popup
3. **Order removed** from system
4. **List updates** automatically

## 🔄 Order Status Workflow

```
PENDING → PROCESSING → SHIPPED → DELIVERED ✓
   ↓
CANCELLED (at any point)
```

**Typical Flow:**
1. Customer places order → **Pending** status
2. Admin reviews → Changes to **Processing**
3. Packaged and ready → Changes to **Shipped**
4. Customer receives → Changes to **Delivered**

**Alternative Flow:**
- Order can be **Cancelled** at any stage if needed
- Cancellations tracked separately in Cancelled count

## 📊 Example Workflows

### Scenario 1: Process New Orders
1. Log into Admin Dashboard
2. Click **Pending** stat card to filter
3. See all pending orders
4. Click status dropdown on first order
5. Change to **Processing**
6. Repeat for other orders
7. Or use bulk update:
   - Select all pending orders
   - Choose "Processing" from bulk dropdown
   - Click "Apply to X orders"

### Scenario 2: Find Specific Customer Order
1. Open Order Management
2. Type customer **name** in search
3. Results filter in real-time
4. Find the order
5. Click **View** to see details
6. Check shipping address and items
7. Update status if needed

### Scenario 3: Generate Revenue Report
1. Check **Total Revenue** card (top)
2. Check **Average Order Value** 
3. Check **Delivered** count
4. Calculate: Revenue ÷ Delivered Orders
5. Track growth over time

### Scenario 4: Prepare Shipment
1. Filter to **Processing** status
2. Sort by **oldest** (oldest first)
3. First orders are ready to ship
4. Click **View** on order
5. Note shipping address and items
6. Click status dropdown
7. Change to **Shipped**
8. Repeat for batch of orders
