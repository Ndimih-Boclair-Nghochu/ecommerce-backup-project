## 🚀 How to Use

### For Store Staff
```
1. Login to admin dashboard
2. Click "🏪 POS" tab
3. Enter customer info
4. Search for products
5. Add items to cart
6. Apply discount (if any)
7. Select payment method
8. Enter amount paid
9. Click "Complete Sale"
10. Print or download receipt
```

### For Managers
```
1. View Dashboard Overview for daily POS sales
2. Check Statistics tab for detailed analysis
3. Use GET /api/admin/pos-stats for reports
4. Compare online vs POS performance
5. Track payment method preferences
6. Monitor discount usage
```

### For Developers
```
1. Use POST /api/orders for order creation
2. Include isInStoreSale: true for POS orders
3. Track paymentMethod field
4. Monitor discountPercent and change fields
5. Query orders with filters
6. Use GET /api/admin/pos-stats for analytics
```
