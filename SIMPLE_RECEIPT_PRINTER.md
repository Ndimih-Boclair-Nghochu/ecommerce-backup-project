# 🏪 SIMPLE RECEIPT PRINTER - Quick Start Guide

## What This Is

A **simple receipt printer** for customers who walk in and buy items. No inventory tracking, no shipping, no online payments - just a clean way to generate and print receipts.

---

## How to Use (3 Easy Steps)

### Step 1: Add Items with Properties
1. Click 🏪 POS tab
2. Enter item name (e.g., "iPhone 15 Pro")
3. Enter price in XAF
4. Set quantity (how many)
5. **NEW**: Add properties (Color, Storage, Size, etc.)
   - Enter property name (e.g., "Color")
   - Enter property value (e.g., "Gold")
   - Click "+ Add Property"
   - Repeat for more properties
6. Click "+ Add Item"
7. Repeat for more items

### Step 2: Enter Customer Info
1. **Name** - Required (customer's name)
2. **Phone** - Optional (customer's phone number)

### Step 3: Generate & Print
1. Optional: Apply discount % (e.g., 10%)
2. Click "✓ Generate Receipt"
3. Click "🖨️ Print Receipt"
4. Done!

## 📋 Item Properties - Detailed Guide

### What Are Properties?
Properties are **specifications or variations** of an item that customers need documented on their receipt.

### Common Property Examples:
```
Electronics:
- Color: Gold, Silver, Black, Blue
- Storage: 64GB, 128GB, 256GB, 512GB
- RAM: 8GB, 12GB, 16GB
- Model: Pro, Pro Max, Standard

Clothing:
- Size: XS, S, M, L, XL, XXL
- Color: Red, Blue, Black, White
- Material: Cotton, Polyester, Silk

Furniture:
- Color: Brown, Black, Gray
- Size: Small, Medium, Large
- Material: Wood, Metal, Fabric

Services:
- Type: Premium, Standard, Basic
- Duration: 1 Day, 3 Days, 7 Days
- Warranty: 1 Year, 2 Years, Lifetime
```

### How to Add Properties:
1. After entering item name, price, and quantity
2. Fill in "Property Name" (e.g., "Color")
3. Fill in "Value" (e.g., "Gold")
4. Click "+ Add Property"
5. Repeat for more properties (e.g., "Storage: 256GB")
6. When done, click "+ Add Item"

### Properties Display:
- **In Receipt Preview**: Shows below item name in small text
- **In Printed Receipt**: Listed with item details
- **Format**: "Color: Gold, Storage: 256GB"

## Quick Example

**Customer comes in and buys:**
- 1 × iPhone 15 Pro @ XAF 850,000 (Gold, 256GB)
- 2 × Phone Case @ XAF 15,000 each (Black)
- Gets 10% discount

**You do:**
```
1. Enter "iPhone 15 Pro" + Price "850000" + Qty "1" → Click Add
2. Add Property: Name "Color" + Value "Gold" → Click "Add Property"
3. Add Property: Name "Storage" + Value "256GB" → Click "Add Property"
4. Click "+ Add Item"
5. Enter "Phone Case" + Price "15000" + Qty "2" → Click Add
6. Add Property: Name "Color" + Value "Black" → Click "Add Property"
7. Click "+ Add Item"
8. Enter Customer Name "John Doe"
9. Enter Customer Phone "+237 6 XX XXX XXX"
10. Set Discount to "10"
11. Click "Generate Receipt"
12. Click "Print Receipt"
```

**Receipt Prints:**
```

2x Phone Case          XAF  30,000
  Color: Black
```
