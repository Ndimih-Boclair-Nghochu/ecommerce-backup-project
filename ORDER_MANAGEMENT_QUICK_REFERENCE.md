## ⚡ Quick Actions

| Action | How To | What Happens |
|--------|-------|--------------|
| **Filter by Status** | Click stat card (Pending, etc.) | List shows only that status |
| **Search Orders** | Type in search box | Results filter in real-time |
| **Sort Orders** | Select from "Sort By" dropdown | List reorders instantly |
| **Change Status** | Click status dropdown on order | Status updates immediately |
| **View Details** | Click "View" button | Order expands with full info |
| **Delete Order** | Click "Delete" + confirm | Order removed from system |
| **Bulk Update** | Select orders + choose status + apply | All selected updated at once |

## 🎨 Status Colors & Meanings

🔵 PROCESSING → Being prepared in warehouse

## 🚀 Common Workflows

### 📥 Process New Orders
```
1. Click [Pending] card
2. See all pending orders
3. Click status dropdown
4. Select [Processing]
5. Repeat for each order
```

### ⚡ Bulk Process Multiple Orders
```
1. Click [Pending] card
2. Check all order checkboxes (or Select All)
3. Choose [Processing] from bulk dropdown
4. Click [Apply to X orders]
5. All updated instantly!
```

### 🔍 Find Specific Order
```
1. Type customer name in search
2. Results filter instantly
3. Click [View] to see full details
4. All info displayed below order
5. Update status if needed
```

### 📦 Prepare Shipment Batch
```
1. Click [Processing] card
2. Sort by [Oldest First]
3. Top orders ready first
4. Click [View] on each
5. Note addresses and items
6. Click status → [Shipped]
```

### 💰 Check Revenue
```
1. Look at top metrics
2. Total Revenue = all sales
3. Avg Order Value = average spend
4. Delivered count = completed orders
5. Calculate: Revenue ÷ Delivered
```
