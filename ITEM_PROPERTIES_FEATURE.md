# 📋 Item Properties Feature - Complete Guide

## What's New

Your receipt printer now includes **Item Properties** - a way to add specifications and variations to items on receipts!

---

## Why This Matters

When customers buy items with variations, they need to know EXACTLY what they bought:

❌ **Without Properties:**
```
Receipt says: "1x iPhone 15 Pro"
Customer questions: "Wait, which color? How much storage?"
```

✅ **With Properties:**
```
Receipt says: 
  1x iPhone 15 Pro
  Color: Gold
  Storage: 256GB
Customer happy: "Perfect, that's what I bought!"
```

---

## How It Works

### Add Properties to Each Item

**STEP 1: Enter Item Details**
```
Item Name: iPhone 15 Pro
Price: 850000
Quantity: 1
```

**STEP 2: Add Properties (Optional but Recommended)**
```
Property 1:
  Name: Color
  Value: Gold
  Click: + Add Property

Property 2:
  Name: Storage
  Value: 256GB
  Click: + Add Property

Property 3:
  Name: RAM
  Value: 8GB
  Click: + Add Property
```

**STEP 3: Confirm**
```
Click: + Add Item

Result on Receipt:
1x iPhone 15 Pro           XAF 850,000
  Color: Gold, Storage: 256GB, RAM: 8GB
```

## Property Guidelines

### ✅ DO:
- Add relevant properties only
- Use clear, concise names (Color, Size, Storage, etc.)
- Use clear, concise values (Gold, Small, 256GB, etc.)
- Add 1-3 properties per item
- Match what customer can see on the product

### ❌ DON'T:
- Add random properties
- Use vague names ("Stuff", "Thing")
- Add properties customer doesn't care about
- Overload with too many properties (>5)
- Misspell property names or values

## Tips for Success

💡 **Speed Up Entry**: Have property information ready before customer leaves

💡 **Be Accurate**: Double-check properties match what customer received

💡 **Stay Professional**: Keep property names capitalized (Color, not color)

💡 **Be Organized**: List properties in logical order (Color before Size)

💡 **Verify**: Read properties back to customer: "Confirmed - Gold color, 256GB storage?"

## Troubleshooting

### Properties not appearing on receipt?
✅ Make sure you clicked "+ Add Property" button
✅ Check the property appears in the orange box below the buttons
✅ Generate receipt after adding properties

### Too many properties to remember?
✅ Write them down while customer is shopping
✅ Keep a cheat sheet by the register for common items
✅ Organize by category (Electronics, Clothing, Furniture, etc.)

### Customer changed their mind about an item?
✅ Click the ✕ button to remove item from receipt
✅ Re-add with correct properties if needed
✅ Properties are saved with items - no loss of data

## Questions?

**Q: Do I HAVE to add properties?**
A: No, but items look more professional and complete with them. Highly recommended for items with variations.

**Q: Can I add unlimited properties?**
A: Technically yes, but 1-3 is best. Too many makes receipt cluttered.

**Q: Will properties increase printing cost?**
A: No, properties take minimal space on receipt.

**Q: Can I edit properties after adding item?**
A: Not directly. Remove the item (✕), re-add with correct properties.

**Q: What if customer doesn't know property value?**
A: Skip that property. Only add what you're sure about.
